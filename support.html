Questions fréquentes

Je suis professeur·e, comment créer un personnage ?
Dans l'app, va dans l'onglet « Fiches » → « + Nouveau personnage », tape un nom, choisis la matière et le niveau, puis appuie sur « Générer la fiche avec l'IA ». Tu peux ensuite modifier chaque question avant de publier.

Comment mes élèves rejoignent-ils ma classe ?
Crée une classe dans l'onglet « Classe », partage le code affiché à tes élèves. Ils l'utilisent avec leur prénom et nom dans « Espace élève » pour rejoindre.

J'ai oublié mon mot de passe (élève)
Demande à ton professeur de générer un code de réinitialisation depuis l'onglet Classe de son espace — ce code te permet de créer un nouveau mot de passe.
